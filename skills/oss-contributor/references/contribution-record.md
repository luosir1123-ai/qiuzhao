# Contribution Record

Record repository URL, upstream commit, issue or opportunity, eligibility rules, branch, changed files, validation commands, diff summary, PR URL, state, review result, merge commit, and dates.

| State | Allowed description |
|---|---|
| Local patch | Prepared and validated a proposed change |
| Open PR | Submitted a contribution for review |
| Closed or unmerged | Participated in review; not adopted |
| Merged | Contribution adopted, with exact scope and link |

Repository stars, organization reputation, and full-project outcomes are context, not personal results.
