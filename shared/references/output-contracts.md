# Output Contracts

## Ranked Role

Return title, company, location, source URL, score, hard-stop status, evidence, gaps, unknowns and recommendation.

## Tailored Resume

Return selected evidence, rewritten bullets, keyword coverage, omitted claims, verification questions, and an updated claim ledger. Preserve factual meaning and metrics. When files are requested, provide editable self-contained HTML and an A4 PDF after print-layout checks.

## Resume Audit

Return atomic claims, evidence status, source references, metric and timeline checks, risky wording, corrected copy, and unresolved verification questions.

## Form Plan

Return section, field label, proposed value, source, confidence and action. Mark required user decisions.

## Application Record

Return company, role, current status, dated evidence, next action, deadline and artifact references. Keep an append-only event history.

## Interview Pack

Return likely questions, evidence-backed answer outlines, gap-repair notes and role-specific questions for the interviewer.

## Contribution Record

Return repository, issue or opportunity, eligibility check, candidate-owned diff, validation evidence, PR state and an honest resume handoff. A prepared or open PR is not an adopted contribution.
