# 参与贡献

这个仓库记录 AI Agent / RAG 应用开发岗位的求职学习过程，也欢迎修正错误、补充练习和改进模板。

## 内容标准

- 结论必须能由代码、实验、官方资料或可复现步骤支持。
- 不把计划中的功能、指标或个人贡献写成已经完成的事实。
- 算法题优先解释识别信号、推导过程、边界和复杂度，不堆砌答案。
- 八股笔记应包含原理、限制、追问和项目联系。
- 外部内容以总结和链接为主，避免复制大段原文。

## 提交建议

- 学习记录：`study: complete day 01`
- 知识笔记：`notes: add RAG retrieval`
- 模板改进：`docs: improve algorithm template`
- 错误修正：`fix: correct TCP handshake note`

## 安全边界

不要提交密码、Cookie、API Key、Access Token、私钥、身份证件号码或其他认证材料。提交前运行：

```bash
bash scripts/check.sh
```
