# Linux 与 Git

## Linux 最低能力

- [ ] 文件、目录、权限和进程查看
- [ ] 标准输入、标准输出、管道和退出码
- [ ] 环境变量、端口和日志定位
- [ ] `curl` 调试 HTTP 接口
- [ ] 容器内外路径和网络的基本区别

## Git 最低能力

- [ ] `status`、`diff`、`add`、`commit`、`log`
- [ ] 分支、合并和冲突处理
- [ ] `.gitignore` 与敏感信息边界
- [ ] 远端、push、pull 和 pull request
