# 计算机网络

## TCP 三次握手

- 一句话：客户端和服务端通过 SYN、SYN-ACK、ACK 确认双方收发能力和初始序列号，建立可靠字节流连接。
- 原理：双方都需要知道自己的发送和接收路径可用，并同步序列号。
- 限制：握手建立连接状态，但不能保证业务请求一定成功。
- 追问：为什么不是两次？四次挥手为什么常见？TIME_WAIT 有什么作用？
- 项目联系：调用模型和检索服务前可能经历 DNS、TCP、TLS，连接池可减少重复建连成本。

## HTTP 与 HTTPS

- 一句话：HTTP 定义应用层请求响应语义；HTTPS 是 HTTP 运行在 TLS 保护的通道上。
- 追问：常见状态码、幂等方法、Keep-Alive、HTTP/2 多路复用、TLS 证书验证。
- 项目联系：流式 Agent 响应常用 SSE；工具 API 需要超时、重试、认证和幂等策略。
