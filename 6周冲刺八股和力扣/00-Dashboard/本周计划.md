# 本周计划

当前执行：[第 1 周 最低面试能力](../08-Weekly/第1周-最低面试能力.md)

## 本周必须交付

- [ ] 7 个每日记录，实际学习总时长不少于 30 小时
- [ ] 7 个不看资料完成的 Python 小程序
- [ ] 8 道算法题记录，其中至少 4 道可以独立重写
- [ ] 操作系统、网络、数据库各完成一组口述问答
- [ ] 能画出并讲清基础 RAG 链路
- [ ] 完成 60 秒自我介绍草稿和第一次模拟面试

## 失败保护

- 连续两天未完成：第三天停止增加新知识，先补复习和最低交付。
- 实际用时不足：删减阅读量，不删闭卷练习、口述和复盘。
- 收到笔试：算法与 ACM 输入输出提高到每天 180 分钟。
- 收到面试：当天建立 JD 需求、个人证据、缺口和追问四列表。
