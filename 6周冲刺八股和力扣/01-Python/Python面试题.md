# Python 面试题

## list 和 tuple 有什么区别？

- 一句话：二者都有序，但列表可变，元组不可变。
- 原理：修改列表会改变同一对象；对元组“修改”通常会创建新对象。
- 限制：元组元素本身仍可能引用可变对象，不能把“元组不可变”误解为内部对象都不可变。
- 追问：为什么某些元组可以作为字典键？什么是可哈希？
- 项目联系：配置快照适合不可变结构；动态消息列表适合列表。

## dict 为什么通常查找很快？

- 一句话：字典用哈希表根据键的哈希值定位槽位，平均查找复杂度为 O(1)。
- 原理：哈希冲突需要额外处理，扩容也有成本。
- 限制：平均 O(1) 不等于永远 O(1)，键还必须可哈希。
- 追问：冲突如何处理？为什么列表不能作为键？
- 项目联系：Agent 工具注册表、会话状态和 Metadata 常用字典。

## 什么是 GIL？

- 一句话：在常见 CPython 中，GIL 限制同一进程内同时执行 Python 字节码的线程数量。
- 原理：它简化了部分对象内存管理，但不等于程序没有线程并发。
- 限制：I/O 密集线程仍可获益；CPU 密集任务可考虑多进程、原生扩展或其他架构。
- 追问：AsyncIO 与线程有什么区别？多进程代价是什么？
- 项目联系：Agent 服务通常 I/O 密集，重点是异步等待模型和工具调用，而不是用线程加速 Python 计算。
