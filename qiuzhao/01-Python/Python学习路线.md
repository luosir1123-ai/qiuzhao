# Python 学习路线

## 第 1 层：能独立写小程序

- [ ] 变量、数字、布尔值和字符串
- [ ] `if / elif / else`
- [ ] `for`、`while`、`range`
- [ ] 列表、元组、字典、集合
- [ ] 函数、参数、返回值和作用域
- [ ] 输入、输出和基础调试

## 第 2 层：能组织程序

- [ ] 类、对象、实例属性和方法
- [ ] 异常处理
- [ ] 文件和 JSON
- [ ] 模块、包和虚拟环境
- [ ] 迭代器、生成器、装饰器
- [ ] 上下文管理器和类型标注

## 第 3 层：岗位工程能力

- [ ] AsyncIO、任务、超时和取消
- [ ] FastAPI 路由、依赖和错误响应
- [ ] Pydantic 数据校验
- [ ] pytest 基础
- [ ] 日志、配置和并发限制

## 每个知识点的完成标准

1. 不看资料写出一个最小示例。
2. 修改输入后仍能预测输出。
3. 能解释常见错误和适用边界。
4. 能指出它在 Agent/RAG 项目中的使用位置。
