# 数据库

## 索引

- 一句话：索引用额外空间和写入维护成本，换取特定查询条件下更少的数据访问。
- 原理：关系数据库常用 B+ 树索引支持等值和范围查询；是否生效取决于查询、选择性和优化器判断。
- 限制：索引不是越多越好；低选择性、函数计算、类型转换或不匹配的联合索引可能无法有效利用。
- 追问：为什么常用 B+ 树？聚簇与二级索引？最左前缀？覆盖索引？
- 项目联系：文档 Metadata、租户、版本和时间字段需要按真实查询模式设计索引。

## 事务与隔离

- 一句话：事务把一组操作作为一致性边界；隔离级别在并发正确性与性能之间取舍。
- 追问：ACID、脏读、不可重复读、幻读、MVCC、锁和死锁。
- 项目联系：增量索引状态更新与文档版本切换需要避免读到不一致的中间状态。
