# 面试就绪度

每项 0～20 分。没有证据链接的自我感觉不计分。

| 维度 | 当前分 | 0 分 | 10 分 | 20 分 | 证据 |
|---|---:|---|---|---|---|
| Python 编码 | 0 | 不能独立完成基础程序 | 可闭卷完成小程序 | 可解释常见机制并完成岗位代码 | |
| 算法手撕 | 0 | 无法独立解简单题 | 高频简单题稳定，部分中等题可完成 | 中等高频题限时稳定并能追问 | |
| 计算机基础 | 0 | 只能识别术语 | 可回答高频主问题 | 可解释机制、边界和项目取舍 | |
| Agent / RAG | 0 | 只能描述概念 | 可解释完整基本链路 | 可讨论评估、可靠性、成本与安全 | |
| 项目表达 | 0 | 无完整叙述 | 可讲清背景、架构和个人工作 | 可承受指标、失败和权衡追问 | |

## 解释

- 0～39：基础建立期。
- 40～59：应该参加面试，但缺口明显。
- 60～79：常见面试具备竞争力。
- 80～100：进入岗位和公司专项强化。

> [!warning] 分数不是录用概率
> 只用于发现短板。每周复盘时依据新证据更新一次，不要每天随意改分。
