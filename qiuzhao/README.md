# qiuzhao

AI Agent / RAG 求职学习系统。

这是一套面向零基础研究生、已经开始投递 **AI Agent / RAG 应用开发岗** 的六周冲刺学习系统。它同时是 Obsidian Vault 和普通 Markdown 仓库，不依赖社区插件也能在 GitHub 阅读。

> [!important] 当前策略
> 不等 Python、算法或八股全部学完再面试。六条训练线每天并行推进，目标是在第 7 天形成最低面试能力，随后根据真实笔试、面试和 JD 滚动调整。

## 快速开始

1. 用 Obsidian 打开本仓库根目录。
2. 从 [学习总览](00-Dashboard/学习总览.md) 查看今天的入口。
3. 执行 [Day 01](07-Daily/2026-08-14-Day01.md)。
4. 每天复制 [每日学习模板](Templates/每日学习模板.md)，完成后补实际用时和证据链接。
5. 每周使用 [每周复盘模板](Templates/每周复盘模板.md) 重新评估优先级。

## 每天 6 小时

| 训练线 | 时间 | 每日产物 |
|---|---:|---|
| Python | 60 分钟 | 关闭资料后独立完成一个小程序 |
| 算法 | 90 分钟 | 1 道新题 + 1 道复习题 |
| 计算机基础 | 75 分钟 | 一组可口述的主问题与追问 |
| Agent / RAG | 75 分钟 | 一篇概念笔记或一次可复现实验 |
| 项目 / 模拟面试 | 30 分钟 | 一段录音、项目讲解或模拟问答 |
| 投递 / 复盘 | 30 分钟 | 更新状态并确定明日第一件事 |

## 掌握标准

算法题统一使用四个状态：

- `new`：第一次接触。
- `learning`：看提示或题解后完成。
- `reviewing`：可以重写，但不稳定或不能讲清追问。
- `mastered`：能在限时内独立编码、通过边界用例并口述复杂度。

“提交通过”不等于掌握。每项进度都应链接到代码、题目记录、口述复盘或实验结果。
