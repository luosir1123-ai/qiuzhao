# 学习资源

## 使用原则

只保留一条主线，其他资料在明确卡点时使用。资源浏览不能替代闭卷编码、口述和实验。

## 算法

- 主线：[代码随想录 LeetCode-Master](https://github.com/youngyangyang04/leetcode-master)。按知识模块和难度顺序学习。
- 原理补充：[labuladong 当前站点](https://labuladong.online/zh/)。在递归、树、滑动窗口、回溯和动态规划框架不理解时查阅。
- 题解核对：[Doocs LeetCode](https://github.com/doocs/leetcode)。完成尝试后核对 Python 实现和复杂度。
- 练习平台：[LeetCode 中文](https://leetcode.cn/) 和 [牛客](https://www.nowcoder.com/)。前者练核心代码，后者补 ACM 输入输出和限时笔试。

## Python

- 主参考：[Python 3 官方教程](https://docs.python.org/zh-cn/3/tutorial/)。每次只读当天相关小节。
- 标准库查询：[Python 标准库](https://docs.python.org/zh-cn/3/library/)。遇到具体 API 时查，不顺序通读。

## Agent / RAG

- 模型和应用概念：优先阅读所用模型或框架的官方文档。
- LangGraph：[官方文档](https://docs.langchain.com/oss/python/langgraph/overview)。第三周开始用于工作流和状态。
- MCP：[官方文档](https://modelcontextprotocol.io/docs/learn/architecture)。第五周系统学习架构和安全边界。
- 向量检索：使用所选向量数据库的官方教程验证过滤、混合检索和评估，不只看二手文章。

## 资料切换规则

1. 语法不会：查 Python 官方教程或当天速查。
2. 题型不理解：先看代码随想录；框架仍不理解再看 labuladong。
3. 已经写完：用 Doocs 核对，不照抄第二套代码。
4. 框架或协议行为：以当前官方文档为准。
5. 学习 30 分钟仍没有代码、图、口述或实验产物：立即停止继续阅读，开始输出。
