# Agent 与 Tool Calling

## 核心区别

- Tool Calling：模型按约定输出工具名和结构化参数，由应用校验并执行。
- Agent：围绕目标重复进行观察、决策、工具调用和状态更新，直到完成、失败或触发停止条件。
- 工作流：开发者预先定义更明确的节点和路由，通常比完全开放的循环更可控。

## 面试必须讲清

- 工具 Schema 如何定义和校验？
- 超时、重试和幂等如何处理？
- 怎样限制步骤数和成本？
- 高风险操作怎样人工审批？
- 状态、短期记忆和长期记忆如何区分？
- 如何记录 Trace 并定位错误工具选择？
