# 评估与可观测性

## 检索指标

- Recall@K：有答案的相关文档是否出现在前 K 个结果中。
- MRR：第一个相关结果排名的倒数均值，关注首个相关结果出现得多早。
- NDCG：考虑多个结果的相关程度和排序位置。

## 生成与 Agent 指标

- 引用正确率、无依据回答率、忠实度。
- 端到端任务成功率、工具选择准确率、平均步骤数和失败分类。
- P50/P95/P99 延迟、超时率、Token 和单任务成本。

## 实验纪律

结果必须同时记录测试集、基线、参数、环境和失败样例。没有测量的数据只能写为目标，不能写为已经获得的提升。

## 高频追问

- 离线指标提高，线上体验为什么可能不提高？
- 测试集如何避免只覆盖容易问题？
- 如何定位失败来自解析、召回、精排、提示还是模型？
