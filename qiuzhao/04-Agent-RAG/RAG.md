# RAG

## 五步链路

1. 文档进入系统后清洗、解析并保留来源信息。
2. 将内容切分为 Chunk，生成 Embedding 和 Metadata。
3. 把向量、文本和元数据写入检索系统。
4. 查询时执行召回、过滤、融合和可选精排。
5. 把相关上下文交给模型生成答案，并返回引用或拒答。

## Embedding

- 一句话：Embedding 把内容映射到向量空间，使语义相近内容在某种距离度量下更接近。
- 限制：向量相似不保证事实相关；领域、语言、切分和模型版本都会影响检索。
- 追问：余弦相似度是什么？为什么需要 BM25？更换 Embedding 后为什么要重建索引？

## 高频失败

- 文档解析丢失结构。
- Chunk 太大噪声多，太小上下文断裂。
- 查询和文档用词不一致。
- Top-K 包含相似但无答案的内容。
- 引用与生成内容不一致。
- 权限过滤放在错误位置导致越权泄露。

衡量方式见 [评估与可观测性](评估与可观测性.md)。
