# LLM 基础

## 最低解释框架

- Token：模型处理文本的离散单位，不等同于汉字或单词。
- 上下文窗口：单次请求可参与计算的 Token 范围，输入、历史和输出预算共同占用。
- Temperature：影响采样分布的随机性参数，不是知识准确度开关。
- 幻觉：模型生成形式合理但缺少事实依据的内容，不能仅靠提示词彻底消除。
