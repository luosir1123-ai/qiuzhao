# Repository Rules

- Keep examples fictional and use `example.com` addresses.
- Never commit real resumes, phone numbers, identity numbers, credentials, or local user paths.
- Keep job matching evidence-based; label inferred requirements and unknowns.
- Form helpers may draft and fill fields, but must not bypass login, CAPTCHA, declarations, or final submission confirmation.
- Run `python3 -m unittest discover -v`, `python3 scripts/validate.py`, and `python3 scripts/check_private_data.py .` before publishing.
